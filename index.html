How to Deploy & Update on GitHub Pages

Follow these simple steps to host this portfolio and keep your added assignments synced online for free.

01

Create GitHub Repo

Create a new public repository named web-portfolio or username.github.io on your GitHub account.

02

Add & Save Assignments

Use the "+ Add Assignment" button to add assignments, then click **"Save HTML for GitHub"** to download the updated index.html file.

03

Enable Pages

Upload index.html to your repo. Go to Repository Settings > Pages and set Branch to main.
